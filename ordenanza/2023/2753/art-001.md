ARTÍCULO 1° EL Honorable Concejo Deliberante de Lobería DECLARA de INTERÉS MUNICIPAL, a los efectos de su financiación por medio del Programa Municipal de Promoción y Estímulo a Micro, Pequeños y Medianos Emprendimientos Productivos (MI FOMEPRO), el proyecto “ESTADO ZEN”, para la compra de un equipo de alta frecuencia, un calentador de piedras, un kit para maderoterapia, un set de manicuría, un set de pedicuría y un set de belleza facial.
